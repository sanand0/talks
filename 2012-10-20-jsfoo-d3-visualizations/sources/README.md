# Authentic JSFoo 2012 D3 source snapshot

The following files are byte-for-byte copies from https://github.com/sanand0/beautiful-visualisations at commit `a9c760ea70dc5797d228d9185fff41b64f2524da` (branch `gh-pages`). It is the speaker's public repo for the 2012 talk. The original repository contains other larger data/assets not duplicated here (weather.csv, weather.svg, shopping.html, etc.); see the full repository.

Included: `nrega.csv`, `jslint.csv`, `wordcloud-ramayana.csv`, `nrega.html`, `jslint.html`, `wordcloud.html`, `tweets.html`, `d3.v2.js`, `tweet-jsfoo.js`. They are **historical primary materials**, NOT updated data or modern API examples. Prefer data files for small honest interactions, link full original HTML sources with attribution, and do not execute 2012 D3 v2 blindly against modern D3.
