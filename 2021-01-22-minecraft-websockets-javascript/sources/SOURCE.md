# Provenance

The historical tutorial files in this directory come from https://github.com/sanand0/minecraft-websocket/tree/master/tutorial, checked out for research on 17 Oct 2026. The source article is a copy from ~/code/blog/posts/2021/programming-minecraft-with-websockets.md (published 20 Jan 2021, updated 2022). These are archival reference materials, not a promise that the undocumented MCWSS protocol is supported in modern Bedrock. Code runs only with suitable versions of Minecraft and Node; do not automatically execute or expose a network server on the user machine.
